## Definition

[Lists](/scenarios/custom-lists/) serve as data sources within the context of a <Glossary>Rule</Glossary> and can be utilized as arguments for compatible operators. Refer to the examples for practical illustrations.

<Aside type="note" title="Operators">
You might be interested in checking the documentation for specific [List operators](/scenarios/custom-lists/).
</Aside>
## Examples

1. **[String similarity](/scenarios/string-similarity/)**: match a string to any of the list values
2. Check if a value `is in` or `is not in` a list
